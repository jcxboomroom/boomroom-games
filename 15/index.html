怎麼玩？

目標：畫家不能說出題目，其他玩家搶先猜中。

  • 每位參賽玩家 Entry：100 銀幣。
  • 本局開始前鎖定獎池：實際付款總額 − 10% 平台手續費。
  • 房內沒有官方玩家名單 API 時，本遊戲只認定透過 Game Event 觀察到且已回報付款的玩家，不偽造玩家。
  • 預設由穩定的第一位已觀察玩家擔任本局畫家；重要題目由畫家本地產生，不把答案廣播出去。
  • 猜對者取得本局獎池；若無人猜中，依預先規則判定為平手處理。
  • 正式比賽結束後不能在同一遊戲實例重玩，等待房主關閉並重新建立下一局。
