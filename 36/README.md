# 第 36 款 · 爆爆方塊攻防

支援加碼：固定入場費 100 銀幣與每局自願加碼分開。共用 SDK revision 10、APP 橋接與後端 TETRIS 引擎需一起更新；維持 TESTING。

## 遊玩與操作

- 單人：一位真人即可直接開始伺服器權威攻防，不須提案或加碼；AI 可選 0–9 位、每位 1–9 級。無 AI 時挑戰自己的分數與生存時間，AI 不投票、不付款、不領獎。Standalone 馬拉松／衝刺與本機 AI 練習保留。
- AI：房間設定的座位與難度會凍結在 Session；AI 使用相同方塊規則、攻擊／垃圾與計分，不投票、不付費、不領獎。真人與 AI 共最多 10 位。
- 多人：至少兩位真人才進入投票與確認，房主開局；可同場加入 AI，但僅真人投票、付款與領獎。採同一七袋序列、3 秒倒數、最多 3 分鐘。點選對手指定攻擊；目標淘汰後改選存活對手。淘汰後可切換觀戰。
- 方向鍵移動／下降，↑ 或 X 右轉，Z 左轉，C 或 Shift 保留，Space 硬降；P 暫停單人。觸控支援長按、多指、輕點旋轉、滑動移動與長滑硬降。

Engine 實作 SRS、七袋、NEXT 5、Hold、Ghost、500ms 鎖定延遲、最多 15 次延遲重置、T-spin、B2B、Combo、All Clear、垃圾抵消及延遲。音效與音樂為本地 Web Audio，可分別開關；震動透過 SDK／Flutter HapticFeedback 或瀏覽器。

## 加碼與分錢

1. 入場費 100 已由正式 Session 收取，按既有平台／創作者政策處理；不放入加碼獎池。正式結算後返回原房間，新對局使用新的 Session；同一已結算 Session 不得重新開局。
2. 至少兩位真人時，每位真人可拖動滑桿或輸入非負整數，不設固定投注檔位。上限為入場費扣除後全員最低實際錢包余额，派彩超出 INT 容量時安全退款；畫面分開顯示本人餘額、100 入場費、全房真人可加碼上限與預估獎池。即使選 0，也須所有真人投票。一位真人時直接開局並略過提案、扣款與派彩。
3. 每個真人目前的提案都會顯示成可直接採用的選項，並標出提案者和票數。票數最多金額成為候選，同票選低額；所有真人各自確認同一金額與設定版本才可開局。改票、AI 設定、離場、失去座位／連線及 60 秒確認逾時會撤銷舊確認。AI 不計入真人票數；單人 AI 練習直接開始，多人含 AI 時仍走真人投票流程。
4. 開局交易先按 user ID 鎖定所有錢包，再驗證餘額、參賽者、局次與確認版本；全部扣款、獎池、唯一帳本及倒數一起提交，任何失敗全部回滾。金額由伺服器決定。
5. 加碼獎池無抽成：2 真人冠軍全拿；3 人以上前 3 名 70%／20%／10%。並列分享所占名次比例，例如 1、1、3 為 45%／45%／10%。整數餘數依名次和穩定玩家順序補足，總額守恆。
6. 最後存活者勝。3 分鐘到時依存活、攻擊、分數、消行排序；淘汰者依存活時間、分數、消行排序。相同數值並列。伺服器按自己的排名原子派彩，UI 只憑 PAID 收據顯示入帳。
7. 正式房間結算頁保留 10 秒檢視排名與派彩，倒數讀伺服器 completion.returnAt，由伺服器結束後自動返回原房間；本機零秒不自行導航。線上結算不再提供「設定下一局」。
8. 房主結束、伺服器逾 10 秒無法續算或不能安全派彩時整池退還加碼；固定入場費不退。錢包容量會保留尚可退還的加碼，防止其他收入導致退款無法完整入帳。

## 伺服器／SDK 契約

`authority-room.js` 用 TETRIS_COMMAND 送操作意圖；每人局次與 seq 去重，持有未確認意圖有限重送。本機先渲染，再用 SYSTEM／TETRIS_PRIVATE 的個人棋盤、ack 和完整對局版本調整。本機預測棋盤與伺服器確認棋盤分層呈現，未確認落塊以半透明顯示；正式分數、消行與攻防統計只讀伺服器快照。TETRIS_QUEUED 即時回傳伺服器收件時間，讓本機預測與權威模擬使用同一操作時間；完整私人快照約 5 Hz，拒絕操作時即時回傳校正快照，投票與準備等房間控制仍即時回覆。收到輸入拒絕時依最新 ack 重排並重播仍有效的本機操作，不清掉整串未確認操作。同版本時鐘封包只校正時鐘、不重繪棋盤；心跳不額外要求同步快照。舊版本、舊局次與重複快照不覆蓋新狀態。5 秒收不到權威快照會停止輸入並顯示非阻擋狀態；25 秒無參賽者心跳淘汰。HTTP 恢復取伺服器棋盤，不信任本機存檔、客戶端分數、攻擊或得獎者。

VOTE、CONFIGURE、READY、START 使用共用 SDK sendCommand 的 UUID 識別碼；READY／START 綁提案 epoch、stake 和 round；後端持久去重。EXIT 撤回大廳確認或中途認輸；APP 返回也會送出。PING／SYNC 支援心跳與恢復。TETRIS_PRIVATE、TETRIS_ERROR、TETRIS_STATE、TETRIS_QUEUED 為保留事件，客戶端不能偽造。

後端 `shared/tetris` 與瀏覽器 Engine／AI／Arena 源碼完全一致；`tetris_session.ts` 鎖持久 Session，按伺服器時間套用合法操作並計算垃圾與排名。100ms 排程批次處理；錢包與獎池在 PostgreSQL 交易內提交。只有正式白名單 URL 會選到特權 TETRIS 引擎；舊 UGC／APP 只可休閒 relay，停用加碼，不宣稱可信銀幣結果。

## 同房觀戰（2026-10-12 本機實作）

- 非原參賽者在房間按「觀戰爆爆方塊攻防 · 免費」進入唯讀頁面；玩家 A／B 與 AI 均可點選，棋盤、分數、消行、攻擊、垃圾、HOLD 與 NEXT 一起切換。目標淘汰時自動選擇存活玩家。
- 原參賽者淘汰後留在同一頁，停止操作、保留原個人權威連線並觀戰其他玩家；不把淘汰當成退出。觀戰者不收入場費，不參與提案、準備、加碼、購買、遊戲結算或操控。
- APP 透過認證 Socket `tetris:watch` 讀取快照並訂閱，只允許同一房間與 roomInstanceId 的進行中 TETRIS Session；原參賽者使用原入口。重連先恢復房間，再重新訂閱。
- `SYSTEM / TETRIS_SPECTATOR` 是保留的唯讀事件。公開投影排除私人 Engine 保存檔、RNG、ack 與錢包；棋盤以 `digits-v1` 的 22 列十位數字字串傳送，再由 AuthorityRoom 還原。共同公開快照由伺服器對每局最多每秒 5 次轉發；切換視角只改本機顯示，玩家不上傳影片、不新增對每個觀眾的連線。
- 每 10 秒續租，租約 30 秒、Redis key 45 秒到期。退出、離房與斷線會取消訂閱；程序意外消失由租約排除。過慢接收端使用 volatile 更新，下一個完整快照可恢復，不累積棋盤佇列。跨實例共用 Redis 發送限速。
- 無有效觀戰訂閱時不建立或發送額外觀戰快照。原有遊戲、房間、語音與連線流量仍存在，伺服器也仍執行原遊戲 tick。TETRIS_QUEUED 操作收據改為只回送本人。
- 使用現有 Node／Socket.IO、PostgreSQL 與 Redis，無新增媒體伺服器或資料表。APP、Server、Games 必須配套發布；本次尚未部署、未執行多人或 100 人壓力測試，免費伺服器容量仍需實際量測。

## 第三階段統一結算（2026-10-14）

只有至少兩位真人時，正式開始按鈕才開啟現有 BoomRoomWagerUI；單真人局（不論是否加入 AI）直接開局並隱藏加碼入口，AI 不投票、不付費且不領獎。隱藏舊重複賭金面板；局內房間 AI 凍結。簡單1／中等5／困難9沿用真正合法移動、Hold／SRS落點與兩步搜索；困難預判遇到頂出／無 active 的下一塊停止搜索，不拋例外或復活。后端與瀏覽器源碼維持逐字一致。

EXIT／forfeit從本局凍結名單標記棄權，仍可觀戰／看完整結算，獎金及公開榜為0；有效排名向前分配，無有效真人整池退款。每人仍只扣一次，派彩及退款有唯一帳本。正式已驗證結果不可再投票／READY／START或修改最終結果；重新連線／重送不延長 completedAt。

本局遊戲分數由 Engine 單一規則計算並由伺服器確認；排行榜規則版本 v13 直接儲存權威本局分數，不再把存活時間、攻擊與分數合成十億級分數。排行榜仍依真人數／AI難度／180秒Battle規則分榜。AI列本局排名但無公開排行榜／錢包；旁觀只公開棋盤和結果，無engine／亂數種子／個人餘額。

共用Server completion含個人最佳／榜名／破紀錄旗標與分數上傳狀態，結果10秒後回原房間；榜服務失敗PENDING重試不阻止返回。伺服器中斷轉成verified無有效結果、退款不登榜仍保留10秒結算。

P3僅執行靜態、單元與非UI PostgreSQL／Socket測試；上述歷史瀏覽器證據不是本輪重跑。後續Web／Windows／Android建置及實際操作、觸控音訊、三AI、十人／觀戰、改票／確認、退出派彩、重連／原房返回及語音由使用者驗收。全部維持TESTING，未commit／push／publish。
